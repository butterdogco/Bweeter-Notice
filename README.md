# Bweeter Notice

Bweeter Notice is the shutdown notice page for Bweeter, a Twitter-like social media platform.

## Why is Bweeter shutting down?

1. BetterMode is removing their free plan, which we've been using. We can't switch to a paid plan because they charge an outrageous amount ($499/month at minimum).
2. It was cool to have, but it was never really popular, and we don't have the resources to maintain it.
3. We want to focus on other projects that we think are more important.

View more details on the notice page: [https://bweeter.butterdogco.com](https://bweeter.butterdogco.com)
